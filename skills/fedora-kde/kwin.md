# KWin — Window Manager / Compositor

KWin is the Wayland compositor and window manager for Plasma 6. Its live config
is `~/.config/kwinrc`; window rules live in `~/.config/kwinrulesrc`; per-screen
state is cached in `~/.config/kwinoutputconfig.json`.

## Golden rule: write, then reload

KWin reads its config at startup and on **reconfigure** — it does **not** poll
the file. `kwriteconfig6` writes the value, but you still must tell KWin to
re-read it.

```bash
# preferred writer (add --notify so KDE apps hear about the change)
kwriteconfig6 --file kwinrc --group Plugins --key blurEnabled false --type bool

# make KWin apply it
qdbus-qt6 org.kde.KWin /KWin reconfigure
```

`qdbus6` is **not installed by default on Fedora**; `qt6-qttools` provides
`qdbus-qt6` instead (some distros name the binary `qdbus6`). If neither is
available, use a direct D-Bus call:

```bash
dbus-send --session --dest=org.kde.KWin --type=method_call /KWin org.kde.KWin.reconfigure
# or
gdbus call --session --dest org.kde.KWin --object-path /KWin --method org.kde.KWin.reconfigure
```

## Reload vs. restart

```bash
qdbus-qt6 org.kde.KWin /KWin reconfigure        # apply kwinrc changes (no flicker)
systemctl --user restart plasma-kwin_wayland    # full KWin restart (blinks, may drop clients)
```

Restart `plasma-kwin_wayland` only when reconfigure is not enough (e.g. a KWin
script was installed/enabled/disabled, or a compositing backend change).

## Effects

Effects are toggled by `<effectName>Enabled` keys in `[Plugins]` of `kwinrc`.
Example values:

```ini
[Plugins]
blurEnabled=true
magiclampEnabled=true
squashEnabled=false
wobblywindowsEnabled=true
```

```bash
kwriteconfig6 --file kwinrc --group Plugins --key blurEnabled false --type bool
kwriteconfig6 --file kwinrc --group Plugins --key wobblywindowsEnabled false --type bool
qdbus-qt6 org.kde.KWin /KWin reconfigure
```

Effect-specific settings live in `[Effect-<name>]` groups (e.g. `[Effect-blur]`,
`[Effect-overview]`). List what KWin currently has loaded over D-Bus:

```bash
qdbus-qt6 org.kde.KWin /Effects            # loaded effect plugins
qdbus-qt6 org.kde.KWin /Effects org.kde.kwin.Effects.loadedEffects
```

## Night light (NightColor)

```ini
[NightColor]
Active=true
```

```bash
# toggle on/off
kwriteconfig6 --file kwinrc --group NightColor --key Active true --type bool
qdbus-qt6 org.kde.KWin /KWin reconfigure

# temperatures: warm at night, neutral while off (Kelvin, 1000–6500)
kwriteconfig6 --file kwinrc --group NightColor --key NightTemperature 4500
kwriteconfig6 --file kwinrc --group NightColor --key TargetTemperature 6500
```

The schedule mode (automatic/sunset-timed/constant) is easiest to set once in
**System Settings → Colors & Themes → Night Light**; the CLI is fine for the
temperatures and the on/off toggle. A `[NightColor]` group may contain only
`Active` while the schedule is still at its default — verify with
`kreadconfig6 --file kwinrc --group NightColor --dump`.

## Window rules (`kwinrulesrc`)

Window rules are one `[<uuid>]` group per rule, plus a `[General] rules=`
index. An empty file looks like:

```ini
[General]
rules=
```

Rules are dense and easy to corrupt (bitmask `types`, `*rule` match enums,
per-key `*match` values). **Create them once in
System Settings → Window Management → Window Rules**, then fine-tune the
generated group with `kwriteconfig6`. When hand-editing, back up first:

```bash
cp ~/.config/kwinrulesrc ~/.config/kwinrulesrc.bak.$(date +%s)
qdbus-qt6 org.kde.KWin /KWin reconfigure
```

To discover a window's `wmclass`/`title` (Wayland has no `xdotool`; `kdotool`
may not be installed), use KWin's own inspector:

```bash
qdbus-qt6 org.kde.KWin /KWin queryWindowInfo    # click a window; prints its properties
```

## Virtual desktops

```ini
[Desktops]
Number=2
Rows=1
Id_1=<uuid-1>
Name_1=Desktop 1
```

```bash
kwriteconfig6 --file kwinrc --group Desktops --key Number 4
kwriteconfig6 --file kwinrc --group Desktops --key Rows 2
qdbus-qt6 org.kde.KWin /KWin reconfigure
```

`Id_N`/`Name_N` pairs are regenerated by Plasma; normally only change `Number`
and `Rows`, or use the desktop-grid / pager GUI.

## Window decorations

```ini
[org.kde.kdecoration2]
ButtonsOnLeft=XIA
ButtonsOnRight=S
```

```bash
kwriteconfig6 --file kwinrc --group org.kde.kdecoration2 --key ButtonsOnLeft MS
qdbus-qt6 org.kde.KWin /KWin reconfigure
```

Button letters: `M` minimize, `S` shade, `H` help, `I` minimize, `A` maximize,
`X` close, `IA`/`XIA` are the common combos.

## Wayland / Xwayland

```ini
[Wayland]
InputMethod[$d]
VirtualKeyboardMode=0

[Xwayland]
Scale=1.0
```

- `[Xwayland] Scale` scales legacy X11 apps (set it to match your screen scale).
- `[Wayland] InputMethod` is a config-array entry; leave it to the GUI unless
  you know the exact syntax.

## Tiling

Custom tiling layouts are stored under `[Tiling][<output-uuid>]` /
`[Tiling][<desktop-uuid>]` groups with a JSON `tiles=` value and optional
`padding=`. Create/edit layouts in **System Settings → Window Management →
Tiling**, or via the on-screen tiles editor.

## Displays (KScreen)

Do not hand-edit `~/.local/share/kscreen/*.json`; drive it with `kscreen-doctor`:

```bash
kscreen-doctor -o                                     # list outputs + modes + geometry
kscreen-doctor output.<connector>.scale.1.25          # set scale
kscreen-doctor output.<connector>.mode.1920x1080@60   # set mode (id or WxH@R)
kscreen-doctor output.<connector>.enable              # enable output
kscreen-doctor output.HDMI-A-1.position.1920,0        # arrange side by side
kscreen-doctor display.<connector>.scale.1.0          # by connector (non-pseudo)
```

`<connector>` is the output name from `kscreen-doctor -o` (e.g. `eDP-1` for a
laptop panel, `DP-1`/`HDMI-A-1` for externals).

Relevant services: `plasma-kscreen.service` (also `plasma-kscreen-osd.service`
for the on-screen confirmation dialog).

## Debugging

```bash
journalctl --user -u plasma-kwin_wayland -b                    # KWin logs this boot
qdbus-qt6 org.kde.KWin /KWin supportInformation                # state dump for bug reports
qdbus-qt6 org.kde.KWin /KWin queryWindowInfo                   # inspect a window
kwin_wayland --version; plasmashell --version
```

If KWin keeps reverting an edit, a running instance rewrote the file on exit —
re-apply with `kwriteconfig6 ... --notify` and reconfigure instead of raw-editing.
